# Wireshark Network Traffic Analysis

## Objective
To capture and analyze live network traffic using Wireshark.

## Tools Used
- Wireshark

## Protocols Identified
1. DNS
2. TCP
3. TLSv1.2 / TLSv1.3

## Steps Performed
1. Installed Wireshark
2. Started packet capture on Wi-Fi
3. Generated traffic by browsing websites
4. Captured DNS, TCP, and TLS packets
5. Stopped capture
6. Saved capture as .pcap file

## Outcome
Learned basic packet capturing and protocol analysis using Wireshark.
